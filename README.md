
# HERLEX | Estudio Jurídico Boutique 💼✨

**Sitio web responsive y profesional** para el estudio jurídico de abogadas *Herlex*, desarrollado como parte del curso de Desarrollo Web en Coderhouse.

---

## ✅ Contenido del sitio

El sitio cuenta con 5 páginas HTML:

- `index.html` – Inicio con imagen hero animada y propuesta de valor
- `nosotras.html` – Presentación del equipo
- `servicios.html` – Detalle de áreas legales de especialidad
- `testimonios.html` – Comentarios de clientas reales
- `contacto.html` – Formulario funcional y ubicación

---

## 🎨 Estética & Diseño Premium

- Estética inspirada en estudios jurídicos de lujo (Beccar Varela, boutique legal).
- Paleta nude + blanco + dorado.
- Tipografías: `Playfair Display`, `Lora`, `Inter`.
- Iconografía de Bootstrap Icons.

---

## ⚙️ Tecnologías y herramientas usadas

- HTML5 semántico (con `header`, `main`, `footer`, `section`)
- SCSS modular (`scss/` + `css/estilo.css`)
- Bootstrap 5 (Navbar, grid, componentes)
- Flexbox y Grid combinados
- Responsive Design con media queries (`rem`, `vh`, `%`)
- Imágenes premium generadas por IA y optimizadas
- Animaciones con `Animate.css`

---

## 📱 Responsive + Accesibilidad

- Mobile first ✅
- Foco visual en navegación por teclado
- Alt en imágenes
- Buen contraste de texto
